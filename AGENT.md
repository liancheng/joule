# Joule

Joule is a language server for Jsonnet. Before you change the code, read these documents:

- [docs/DESIGN.md](docs/DESIGN.md): the goals, the architecture, and the design decisions. Read it to find where a change goes and which constraints apply.
- [docs/STYLE.md](docs/STYLE.md): the rules for code, tests, comments, commits, and documents. Obey it in all changes.
